## Cross-cutting findings

- Consolidation in oi-browser is observation copying, not supported learning. The native adapter records raw observation and durable learning separately, preserves evidence IDs, deduplicates repeated polling, checks freshness, and supports retraction.
- The oi-browser CLI route is not an inference proof: ORCA is status-only, local is deterministic simulation, and the timeout branch returns `exitCode: 0`. The native router uses explicit `installed`, `authReady`, `health`, `executionSucceeded`, timeout and nonzero failure states.
- `AgentDOMBrowserService` is static HTTP/HTML extraction. It cannot prove authenticated state or live interaction. The native snapshot is explicitly `STATIC_HTTP` unless a live executor supplies a verified accessibility snapshot.
- Parser, annotation, and executor must share one semantic identity. The native adapter returns the same `elementId` in the snapshot and rejects duplicate/ambiguous IDs; final submit remains behind existing transport/authority checks.
- oi-browser's SQLite persistence is durable enough for its demo application but does not replace marketing-seeding's lease/migration model. No second DB is introduced.
